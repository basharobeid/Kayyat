## 1. Vision & Mission

### Vision
> **Khayyat** will become the digital infrastructure layer for everything clothing-related in the Arab world — from a simple pants hem to a wedding dress design, from sourcing rare fabric to running a full tailoring workshop.

### Mission
> We give every person — customer, tailor, or fabric seller — the tools, opportunities, and trust to connect, transact, and create. We bind craftsmanship to technology without losing the soul of the craft.

### Core Values

| Value | Practical Application |
|-------|----------------------|
| **Trust** | Multi-level verification + reviews tied to completed transactions |
| **Simplicity** | Service request in 3 steps, zero friction |
| **Craft** | Showcasing skill, taste, and detail in every interface |
| **Fairness** | Transparent commission, no hidden fees, support for small tailors |
| **Community** | Strengthening the local economy, supporting local talent |
| **Innovation** | Adopting AI when useful — never for show |

## 2. Problem & Solution

### 🩸 Current Problems

#### For Customers
- Doesn't know which good tailor is nearby.
- No idea about pricing before visiting.
- Must physically go, wait, and return.
- No quality documentation or reviews.
- Hard to find specific fabrics.
- No order tracking or delivery estimate.

#### For Tailors
- Entirely dependent on word-of-mouth and location.
- No digital marketing channel.
- Dead seasons with no work.
- Hard to source fabrics at competitive prices.
- No invoicing or profit-tracking system.
- No distinction between professional and amateur tailors.

#### For Fabric Sellers
- Dead inventory that never reaches the right audience.
- No B2B channel to tailors.
- No visibility into existing demand.

#### For Delivery Providers
- No delivery system tailored for garments (delicate, needs care).
- Limited job opportunities in this niche.

### 💡 The Khayyat Solution

| Problem | Khayyat Solution |
|---------|------------------|
| Finding a tailor | Smart search + map + filters + recommendations |
| Price uncertainty | Competitive quote system |
| Quality assurance | Verified reviews + portfolio + trust badges |
| Fabric sourcing | Full fabric marketplace + reverse requests |
| Delivery | Integrated delivery with live tracking |
| Tracking | Order timeline with clear stages |
| Trust | Dispute system + mediation + secure payment |

## 3. Market & Competitor Analysis

### Target Market (TAM / SAM / SOM)

| Layer | Description | Estimate |
|-------|-------------|----------|
| **TAM** | Tailoring & fabric market in MENA | ~$12B |
| **SAM** | Digital clothing services in major cities | ~$1.8B |
| **SOM** | Achievable share in first 3 years | ~$45M |

### Competitors

| Competitor | Strengths | Weaknesses | Our Edge |
|------------|-----------|------------|----------|
| Facebook/WhatsApp groups | Free, local | Chaotic, no guarantee, no tracking | Organized system + secure payment + reviews |
| Home services apps | Large user base | Not tailoring-focused | Deep specialization + artisan community |
| Traditional tailor shops | Local trust | No digital presence | Full digitization + wider reach |
| Fashion platforms | Aesthetic | No alteration services | Service + product integration |
| Delivery apps | Speed | Don't understand garments | Specialized delivery + precise tracking |

### Unique Selling Proposition (USP)
> **Khayyat is not just an app to find a tailor. It is the complete ecosystem of the clothing industry: from idea, to fabric, to tailoring, to delivery, to review.**

## 4. Business Model

### Revenue Streams

| # | Stream | Expected Share | Phase |
|---|--------|----------------|-------|
| 1 | Service commission (10–15%) | 55% | MVP |
| 2 | Fabric sales commission (5–10%) | 20% | Phase 2 |
| 3 | Delivery fees | 10% | Phase 3 |
| 4 | Premium tailor subscriptions | 5% | Phase 4 |
| 5 | Ads & featured placement | 5% | Phase 4 |
| 6 | Business accounts (B2B) | 3% | Phase 5 |
| 7 | SaaS tools for workshops | 2% | Phase 6 |

### Pricing Structure

```
Customer pays: $100
├── Platform commission: $12 (12%)
├── Payment processing: $3 (3%)
└── Net to tailor: $85 (85%)
```

> **Note:** Rates are adjustable per market and competition. The architecture must allow changes without rewriting code.


### 8.3 Shadows

```
sm:  0 1px 2px rgba(0,0,0,0.05)
md:  0 4px 12px rgba(0,0,0,0.08)
lg:  0 8px 24px rgba(0,0,0,0.12)
xl:  0 16px 48px rgba(0,0,0,0.16)
```

### 8.4 Components

#### Buttons
```
Primary:   Gold background + white/dark text
Secondary: Border + dark text
Ghost:     Transparent + text only
Danger:    Red background + white text
Success:   Green background + white text
```

#### Inputs
```
- Height: 44px (easy touch)
- Border: 1px light grey
- Focus: gold border + soft shadow
- Error: red border + message
- Success: green border + icon
```

#### Cards
```
- White background
- Soft shadow
- 12px rounded corners
- Image + title + description + price + action
- Hover: deeper shadow + slight lift
```

#### Badges
```
- Verified: ✓ (green)
- Trusted: 🛡️ (blue)
- Featured: ⭐ (gold)
- New: 🆕 (orange)
```

### 8.5 States

| State | Description | Design |
|-------|-------------|--------|
| Empty | No content | Icon + message + suggested action |
| Loading | Loading | Skeleton or Spinner |
| Error | Error occurred | Icon + message + retry |
| Success | Operation succeeded | ✓ + message + next action |
| Partial | Partial content | Message + available content |

### 8.6 Accessibility

- Color contrast ≥ 4.5:1 for text
- Clear focus ring
- Keyboard navigation
- Alt text for images
- ARIA labels for interactive components
- Screen reader support
- Scalable font size

## 12. Security & Privacy

### 12.1 Authentication & Authorization

- **Password hashing:** Argon2id
- **JWT:** Short-lived access token (15 min) + long-lived refresh token (7 days)
- **Refresh rotation:** On each refresh, old token invalidated
- **Session invalidation:** On password change / logout-all
- **RBAC:** Role-based access control on every endpoint
- **Rate limiting:** Redis-based per IP + per user
- **CSRF:** SameSite cookies + token for state-changing requests
- **XSS:** Output escaping + Content Security Policy
- **SQL Injection:** Parameterized queries via ORM
- **File uploads:** MIME validation, size limit, virus scan hook
- **Secrets:** Environment variables, never committed
- **Audit logs:** All admin actions recorded

### 12.2 Privacy Rules

- Customers control what tailors see.
- Tailors see only: name, city, request details, contact (after acceptance).
- Measurements and photos are private by default.
- Admin access is logged and justified.
- GDPR-style data export and deletion endpoints.
